Butuh keputusan Anda

Four things are still open. Each one blocks work that cannot start until it is answered, so they sit at the top rather than at the end.

  1. Art direction — section-transition language, and what “surpass the benchmark” means concretely. This page is tokens and components; the direction sits on top of them. Phase 1b task 1.
  2. Hero copy — the Indonesian headline, subheadline, and meta description. Decided together with the type scale, because a three-word headline and a twelve-word one need different sizes. Phase 1b task 2.
  3. Icon library and date handling — both are dependencies, and both must fit inside the performance budget before anything imports them. Phase 1a task 1.
  4. Pricing on /booking — needs your rate card: flat rate, or peak and off-peak, or weekend. Until it is answered no number renders on either page.

Layer 3 is the half that usually gets skipped. Every component rule in this file reads from a --slot-*, --pill-*, --button-*, --input-* or --card-* token, never from a primitive. Copy that indirection into Phase 2 — a component that reaches straight to var(--white) looks identical today and breaks the moment the theme moves.

Slot cell

One column, full-width rows. Chosen for one concrete reason: “Menunggu Konfirmasi” is 20 characters. A 3-column grid at 375px gives ~110px per cell and the label cannot fit at all; 2-column forces truncation. Full-width fits it at full size and yields a tap target well above 44px. Click an available slot to see the selected state, and click it again to deselect.

Selection is exposed to assistive tech, not just to CSS. The state lives in aria-pressed and the class hangs off it, so a screen reader announces the change. A class-only selection looks correct and is silent — and this is the pattern Phase 2 copies into the product's core interaction.

Unavailable cells stay visible and focusable via aria-disabled, never native disabled. A user needs to see that 18.00 is taken, not wonder why the list skips it.

Elapsed hours are not booked hours. GET /api/availability returns booked for today's past slots, but the client already knows the current time and the canonical slot starts, so it derives “elapsed” itself — no API change, and the contract stays firm. The order section collapses them into one “Sudah lewat (N)” row rather than rendering nine “Terisi” labels that make the day read as sold out. See the order-section brief in .impeccable/surfaces/.

Date pills

Fully rounded so the row reads as horizontally scrollable without a hint — the one place the pill radius is used. overscroll-behavior-x: contain stops a swipe bouncing the page. Click to select; scroll the row sideways; tab through to reach the unavailable one.

Buttons & inputs

48px height — comfortably above the 44px tap minimum.

Nomor tidak valid. Gunakan format 08xx atau 62xx.

The error state does not depend on its border alone. A border that carries a state by itself must clear 3:1 (WCAG 1.4.11). --red-300 on a white field computes to 1.90:1 and fails, so the boundary is --red-800 at 8.31:1 and the field fills --red-100 — two signals, neither of them hue-only. Errors tie to their field via aria-describedby, and focus rings are never removed. Tab through this page to check every focus state.

GSAP has no built-in reduced-motion handling, so a direct gsap.to() in a component is banned — that is exactly how one component ships without the check. Which effects the page actually uses is the user's choice, asked before the code is written; see docs/design-process.md.
